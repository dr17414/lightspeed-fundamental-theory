## 2. 連續目標與「以 c」的精確意義

使用 signature (+---)、`□=∂_t²−∇²`，固定 ℏ=c=1。
令 z=y−x、s=z_t²−‖z_space‖²。本題目標是以下**給定的**推遲分布：

$$
G^{(4)}_{R,0}(z)=\frac{\theta(z_t)}{2\pi}\delta(s),\qquad
\Box_y G^{(4)}_{R,0}(y-x)=\delta^{(4)}(y-x).
$$

這是外部校準目標，非本稿導出的度規或速度。來源／接收的參數次序以 x→y 為準，
不把文獻的矩陣 row／column 慣例當物理箭頭。測試時包含跨光錐的函數以檢查
非零正規化，也包含支持嚴格位於錐內及錐外的函數以檢查尾部；零核不算達成目標。
不對 delta 分布要求光錐上的逐點有限值。

[後續原文 arXiv:1701.07212v5](https://arxiv.org/pdf/1701.07212) §2.1–2.2、式(10)、(23)
用於核對此處的維度／支持慣例：1+1 維無質量目標是
`G^(2)_{R,0}(z)=θ(z_t)θ(s)/2`，填滿未來錐內；它仍有光錐前緣，但不是
本題的純錐面支持目標。有質量 3+1 維亦有錐內 tail，不能要求整個 massive Green
只在錐面。因此 **1+1 維與 m>0 本輪只作文獻作用域對照，不作第二個研究分支**。

必須分開三件事：

| 主張 | 此域內的意思 | 結論上限 |
| :--- | :--- | :--- |
| 不超過 c | 在正確保序的 Minkowski 嵌入中，僅沿因果未來的支持不跨到類空域 | 相容性來自已給的因果 order／背景；不生成傳播 law，也不推出 finite c 已湧現 |
| 以 c 的錐面目標 | 本輪無質量 3+1 維極限分布須是上式，無錐內 tail 且正規化正確 | 不只證支持在錐內；不把單一粒子每條離散路徑稱物理光線 |
| 平均與單次 | 期望的弱極限、單次抹平讀值的漲落，分屬 §5 的兩項義務 | 前者不推出後者；兩者也都不是實際裝置或 r3 回訊 |

## 4. 機率域、端點與抹平讀值的型別

固定一個 bounded causally convex Minkowski diamond D、來源 x∈int D、
長度單位 L>0，全部不隨ρ改變；r=ρL⁴ 是無量綱密度。
校準 law 為 D 中相對 `d⁴y` 的 homogeneous Poisson、強度ρ。**這是紙上機率域，
沒有實際撒點。** 對 D 內端點，因果凸性保持完整區間，不以縮小實體窗口避開漲落。
不主張任意有限 diamond 已具有 full-Minkowski 的全部對稱性。

參照文獻的固定端點比較，每個 `(x,y)` 都以同一 Π_ρ 與另加的端點取得
參照類的核值。用 `Q_ρ(x,y;Π_ρ)` 暫記該已發表類的評估對象；此符號不指定
新的核或獨立的 `(x,y)` 抽樣。**在同一ρ的所有y比較共用同一Π_ρ**，不能每對
端點重抽，或在計算方差時將不同y的核值當獨立。
來源／probe 端點插入是外加校準，不是從無標記 causal set 選出了器件。
這是一個 augmented-endpoint 的隨機校準族，不等同某台裝置的接收紀錄。

對每個事前固定、實值、無量綱 `φ∈C_c^∞(int D)`，規定比較泛函的型別為

$$
F_\rho[\varphi]=L^{-2}\int_D Q_\rho(x,y;\Pi_\rho)\varphi(y)\,d^4y,
\qquad F[\varphi]=L^{-2}\langle G^{(4)}_{R,0}(\cdot-x),\varphi\rangle.
$$

Fρ 與 F 均無量綱。未來須先證可測性與積分／矩存在，才能使用下面量詞。
這是誤差對象的定義，不是本稿已算出的值；測試函數可跨光錐或含來源，不依
未來結果排除難點。φ、D、L、x 不隨ρ或Πρ縮放／挑選，不新增可調抹平尺度。
座標、Lebesgue積分及φ只用於外部比較，不傳入 §3 的權重。
若日後改為 sampled source／receiver、Poisson quadrature 或器件窗口，是不同
隨機讀值，須另定契約；不能把本泛函的期望／方差直接搬過去。

## 5. 收斂方式、誤差量詞與單次漲落

以下都是**待證或待限定否定的命題**，不先保證成立。

### 5.1 M：期望的分布弱收斂與平均誤差

$$
\forall(D,x,L,\varphi)\ \forall\epsilon>0\ \exists r_0<\infty
\ \forall\rho>0\;(\rho L^4\ge r_0\Rightarrow
|\mathbb E_\rho F_\rho[\varphi]-F[\varphi]|\le\epsilon).
$$

量詞域是 §4 的全部固定合法輸入，r₀ 可依該組輸入與ε，但不依撒點結果。
第一份研究須給解析可檢查的誤差上界 `e_(D,x,L,φ)(r)→0`，或清楚只證定性極限而
誤差界仍 OPEN；不能由「存在r₀」虛構可用 density cap。沒有宣稱對所有φ的共同
上界、對增長 D 的 uniformity、逐點收斂或光錐上的有限數值。
期望與測試函數積分的交換、delta 正規化及來源附近控制都要明證；不只引用摘要。

### 5.2 V：單一Πρ的抹平漲落是獨立義務

須對**同一 §4 泛函**另問

$$
\forall(D,x,L,\varphi)\ \forall\epsilon>0\ \exists r_1<\infty
\ \forall\rho>0\;(\rho L^4\ge r_1\Rightarrow
\mathbb E_\rho|F_\rho[\varphi]-\mathbb E_\rho F_\rho[\varphi]|^2\le\epsilon^2).
$$

要證明 V，須有同一Πρ中不同probe區間的聯合 law／協方差及可檢查上界，
不能假設不同link獨立，也不能把「每條路徑有權重」當機率正規化。
若 M、V 都證得，才可另以證明支持對每個固定合法φ的機率收斂目標：
`∀ε,δ>0 ∃r₂ ∀ρ (ρL⁴≥r₂ ⇒ Pρ(|Fρ[φ]−F[φ]|>ε)≤δ)`。
這不是 a.s. 結果，更不是所有φ同時成立、有限次觀測已證明或實際器件可靠。

本題不宣稱 **almost sure convergence**：未選跨密度的共同機率空間／coupling。
若要問a.s.、典型因果集上的 sampled-pair 結果、uniform tails 或漸近速率，需要
另外固定新量詞與所需前提。M通過／V未證或不成立必須分別記錄，不以平均補位。
