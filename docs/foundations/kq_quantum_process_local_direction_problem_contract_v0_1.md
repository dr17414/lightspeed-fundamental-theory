## 1. 問題、輸入的有限清單與來源帳

**問題：** 給定有限、閉合且連通的無向量子過程網絡，能否由

在**每一條接線**上選出一致的局部方向？本輪只要求「數學上的
接線定向」，不把它逕稱為訊號、因果或熱力學時間方向。

完整輸入只能是下列**六類已列名**的資料，圖的大小可變，
但每個實例均有限；維度與運算子須於後續獨立資料門檻逐一登記。

## 2. 待求的條件、方向位置及唯一性

候選必須在規格門檻、看任何結果前，交出一個有限描述、可在
任一登記輸入上判定的 Boolean 條件 $\chi(\mathcal D,o)$。
$\mathcal D$ 僅是 §1 六類輸入，$o$ 把每條無向線的一端標為
箭尾、另一端標為箭頭；$\Omega(\mathcal D)$ 是所有此類
**完整逐線定向**的有限集合。端口的局部進／出分解只是 $o$
在各區域的誘導結果，**不另作原始輸入**。條件不得含未列名
的自由參數或按具名案例重新選定的係數。

令 $\bar o$ 把連通圖所有線的箭頭同時反轉，令
$S_{\mathcal D}=\{o\in\Omega(\mathcal D):\chi(\mathcal D,o)=1\}$。
本稿**事先選定「唯一到全局翻轉為止」**這一目標：

$$S_{\mathcal D}=\{o_*,\bar o_*\}\quad\text{恰為一對，}\qquad
\chi(\mathcal D,o)=\chi(\mathcal D,\bar o)
\quad(\forall o\in\Omega(\mathcal D)).\tag{D.1}$$

這個選擇**從定義上不回答絕對箭頭**；若日後要問絕對方向，
須另立契約。「完全唯一」不合本目標；多於一對的等價類、只有部分接線
可定向，或各端口各自選出相衝突的方向均不是 PASS。
不同連通分量各自反轉的情況在本輪域外，不能試算後把一個
連通 FAIL 拆成多個分量。圖和 Hilbert 空間的同構、端口索引
置換、接線兩端因子交換、局部 unitary 基底改寫及 §1 所定的
**整組局部操作**正比例重標定，必須把 $S_{\mathcal D}$ 同變地送到新輸入的
$S_{f\mathcal D}$；不能藉標號或矩陣列印順序選出那一對。
對正比例更換須先回到 §1 的規一化代表元，再比較結果。

另列一項**本 repo 新增**而非 S6／S7 已證的反么正穩健性
要求：在一致選定的端口正交基底中，把**整個網絡所有**
$M_{v,i}$ 和 $\omega_e$ 同步複共軛，得 $\mathcal D^*$；
對每個 $o\in\Omega(\mathcal D)$ 均要求
$\chi(\mathcal D^*,o)=\chi(\mathcal D,o)$，故
$S_{\mathcal D^*}=S_{\mathcal D}$（圖及接線不變）。
更換這些基底再作共軛的情況由前述 unitary 同變涵蓋。
**不**要求單一端口或單一區域的部分轉置：它一般不保
糾纏正算子的正性，不是 §1 域內的資料同構。這項條款
排除只憑全局複共軛的符號差選定向；若未來要以物理
反么正結構作新 primitive，必須重新立約，而不能偷偷
以 S6 的反演敘述取代此處的全網絡條件。

$\chi$ 的**全部自變數**只得是 §1 的無向 incidence、
有限維向量空間、正算子、接線態以及由它們算出的定義良好
的數值。不得在輸入、公式、演算法中預設 S6 原有的
兩種時間端型別、光錐、metric、時間先後、既有因果箭頭，
也不能用「先準備／後量測」給端口定義。若另需外加的
方向場、參照端、指定因果序或隱藏的排序參數，須在契約
層重新列為 primitive 並重新審查，不能在資料或規格門檻
暗加。候選可以利用 $\omega_e$ 的**已登記物理內容**，
但須依 §3 的**資料構造來歷**區分從資料選出的 $o$ 與原本
已外給的非對稱結構。不得依具名圖的名稱寫例外分案；
同一有限法則須作用於全目錄。

## 4. 全域判定、後續三道門檻及不能推出

資料門檻必須先固定公開目錄及 §3.1 保留集、正比例／
基底／複共軛識別、全部四類 A／B 變體及**所有正式輸入**
的逐算子構造來歷，並逐項核定型別與 $\Delta>0$；
候選不能在它們之後選擇有利的樣本。
規格門檻
在任何試算前固定 $\chi$ 的完整式、可重複求值方法、
$S_{\mathcal D}$ 的枚舉／證明方式、各型別及不變性檢查，
並事先寫明公開與保留集全部具名網絡中每一個 $\Delta$
