## 2. 「有限、有方向」必須分成不同義務

| 用語 | 欲檢查的數學／物理性質 | 不能由它直接得到什麼 |
| :--- | :--- | :--- |
| 有限整體 | 某次物件的事件總數有限 | 只說支持為有限集幾乎沒有內容；不給跨大小的上限或物理速度 |
| order-interval 局部有限 | 每對可比較事件之間的事件數有限 | 不直接限制某事件全部未來支持的數量、空間距離或傳輸速率 |
| 統一有限出支持 | 同一規則在全部域、全部事件的出支持數均不超過同一有限 k | 不給有限入支持、有限延遲、近鄰、空間局部性或非零傳輸 |
| 因果方向 | 支持中的接收事件必須位於來源事件的嚴格未來 | 不選空間方向、慣性系或特權時鐘；回程也是到較晚的 A 事件，不能反轉 order |
| 有限窗口內傳輸 | 在事前宣告的紀錄窗口內，有依準備改變的接收 law | 需要動力學／紀錄和窗口輸入，不能由支持箭頭代替 |
| 物理有限速度／不變 c | 經操作性時計與尺規定義的速率界，及明訂觀察者間的比較 | 不能把有限度數、有限 hop 數或外加「每 tick 一格」改稱光速已導出 |

本問題只先處理第三、第四列的**結構性可選性**；非空性使零支持不充作答案。
即使得到肯定結果，也只是 C2 的一部分，不會由此關閉 C1、C3–C6 或 B1–B7。
統一有限度數是有待檢查的一條窄路線，**不是所有物理訊號必須滿足的公理**。
若這條路被排除，不准把 no-go 擴張成「因果結構不能承擔任何訊號」。

## 3. 第一個紙上子問題：精確輸入與輸出義務

### 3.1 域與輸入

域為所有非空有限偏序 `P=(V,≺)`，≺ 嚴格、遞移、無自反；V 的基數可任意大。
計數／基數是這個有限組合物件的資料，不把它等同已校準的物理體積。
規則對每個 `p∈V` 接受 `(P,p)`：p 只是詢問「此事件的出支持」的參數，
不是全域預選的 observer、worldline 或 privileged frame。
容許規則查閱整個 P；**沒有暗加局部演算法或有限 order-depth 依賴**。

只有 order 可作選擇依據。用於表示 V 的編號、檔案次序、canonical labeling、
座標、seed 或事先排列，不得成為破除等價事件的物理輸入。
若欲加入真正的物質標記、邊界、root、時計、權重或 law，必須另列新的條件域；
這會改變本子問題，不能悄悄加入後仍回答原來的 order-only 存在性問題。

### 3.2 輸出型別及待證量詞（不是選擇法）

問題只指定輸出型別：一個確定性支持集 `S_P(p)⊆V`。
尚未定義任何取得 S 的公式、演算法、參數值或模型。未來須同時回答：

1. **方向：** 每個 `q∈S_P(p)` 都滿足 `p≺q`；不含自身或不相關事件。
2. **非空：** 只要 p 有嚴格未來事件，`S_P(p)≠∅`；沒有未來時，支持為空。
   這是欲檢查規則的數學義務，並非聲稱每個事件都應發出物理訊號。
3. **同構等變：** 對每個偏序同構 `φ:P→P'`、每個 p，
   `S_{P'}(φ(p))=φ(S_P(p))`。不能挑一個依編號的代表而只要求同構後度數相同。
4. **統一有限上限：** 要問的存在性量詞是

   $$
   \exists k\in\mathbb N_{\ge1}\;\exists S\;\forall P\;\forall p\in P:
   \quad |S_P(p)|\le k,
   $$

   其中 S 同時滿足前三項，k 不依 P、p 或總事件數。這不等同
   `∀P ∃k_P`，更不等同在一個預設 N 上找到上限。本稿沒有選定 k。

不額外要求選出的關係生成原 order、所有目的地可達、入度有界、最近鄰、
單一路徑或兩條移位鏈。這些都是尚未加入的條件，不能在結論中偷渡。
本題沒有輸出振幅、transition probability、狀態更新或 receiver 紀錄；
非空支持仍不是非零實際傳輸的證明。

### 3.3 對稱性、域限制與結論的帳

未來研究必須檢查保 p 的自同構如何作用於候選接收事件；不可用未申報的
tie-breaker 隱藏多解。若義務相衝突，交完整限定證明，不為成功而事後刪除
對稱輸入、改為可空、讓 k 隨 N 增長或以編號選點。此稿不先構造對稱反例。

全域否定若成立，只排除以上四項的聯立。若後續要限特定 order 類、引入
真正的 boundary／matter 資料、改成隨機等變 law 或可無限支持的加權 law，
須先記錄原否定與改題原因，提交新的問題範圍；**不是**本題已默許的答案。
不准把「所有有限偏序」上的否定改寫成「典型 manifoldlike causet」上的否定，
也不准用一個有限樣本的肯定替代全域量詞。

## 5. 通向實際 C2 與光速仍需的橋接

即使支持可選，未來還須逐項另證，不在本稿預選答案：

  只給 `p≺q` 或一個 graph 不足以完成回訊契約。
- **裝置與回程：** A／B 身份、局部儲存、B_in／B_out 及 A 較晚的接收事件
  如何實現；不能讓 B→A 變成回到同一個早先 A 事件的因果循環。
- **有限性與尺度：** 入支持、空間 locality、延遲與資源分別立命題。
  hop 數不直接給時長；C1 tick 或 density／clock calibration 若保留，仍是 X-C 輸入。
- **物理 c：** 先有具名 clock／rod、單位與 observer／matter law 比較，才可提出
  有量綱速度界或不變 c；有限出度不承擔它，c 的數值仍不能由裸計數指定。
- **上游判準：** 若將來替換回訊研究 C2，C1、C3–C6 的依賴仍列帳；須重新
  證兩段／同一無回應對照／串接與完整紀錄，不沿用舊結果宣稱新版 law 已合格。
  整體若仍有外加背景與器件，只能稱 X-C；一個 order-only 組件不把整體升格 X-I。
