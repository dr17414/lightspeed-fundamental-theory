## 3. 要識別的紀錄與容許輸入

下列是未來模型必須解釋或明示條件化的**目標欄位**，不是一份模型或實作 schema。

| 紀錄需求 | 來源／不可省略的義務 |
| :--- | :--- |
| A 的準備、B 的首次接收、B 的回應發出、A 的最終回讀 | 各操作與讀出事件的 device identity／事件身份；不能把任意 chain 當物質軌跡或接收紀錄 |
| 請求／回應的配對與方向 | 若用 request tag、額外 mark 或外部配對資料，列為 conditional input；tag 本身不證明訊號傳輸、相互作用或 intrinsic 識別 |
| 是否收到、回應是否唯一、窗口型別 | 事前申報是順序區間還是鐘窗口，端點／開閉／截斷與缺失讀值規則；無接收、無回應、延遲、multipath／誤配對不因窗口或成功條件而事後排除 |
| 兩段操作依賴與無回應對照 | A→B：比較 B 自己完整接收紀錄的分布，須因 A 的合法準備干預而不同。B→A：固定 A 準備與本地記憶，A 回讀須因 B 端回應而不同；移除／阻斷／無回應替換的合法對照中，B 回應造成的依賴須消失。A 只記得自身準備不算訊號 |
| B 的回應方式與合法操作類 | 事前申報固定自動回應或可選設定。自動模式須指出可合法比較的接收內容／回應操作，可選模式須宣告可比較設定；二者都不能直接向 A 輸入 B 設定／控制標籤，亦不能只比較事後挑選的接收成功個案 |
| propagation support 與先後 | 指明 strict chronology、weak causal relation 或模型內有效 support 的型別；相容性不等於非零傳輸或實際 detection |
| 若要報時間：刻度、讀值、回應延遲、窗口與誤差 | 分別申報幾何 proper time、實際 tick、顯示值的來源；不能由 bare order 直接給 duration，不能把 B_in／B_out 合成同一事件以消除未知延遲 |

操作間的可比較性也須列前提：若存在不同 state／boundary／先前記憶，不能把其影響
誤稱為準備操作的效果。單一請求是問題範圍，不表示資料只有成功的一次；重複性或
「一般情況」將來仍須具名擴域，不由單次存在推得。

**窗口型別不能省略。** 若用順序區間，申報端點、relation 型別、開閉與有限事件
範圍的依據；順序／事件計數不直接給 duration。若用鐘定窗口，鐘、刻度、校準、
起迄讀值與必要的跨裝置比較均是額外 X-C 條件式輸入，要記來源及接觸依賴。
同一事前固定的選取／讀出規則適用於各操作與阻斷對照，不能依是否成功回應換窗口。
窗口結束仍未收到時照原規則記未收到／不可用；未觀測的窗口外事件不虛構，也不
事後延長窗口把失敗改成成功。若另有已觀測的延遲資訊，其取得範圍亦須事前申報。
本修訂沒有選定窗口實例、鐘模型、B 回應法則或設定值。

## 4. 實現論證需回答什麼（尚未給出答案）

1. **完整 law：** 給出準備、傳輸、接收、回應與讀出之間的完整條件關係／狀態法則。
   如使用機率／量子 law，須有 state、pairing、positivity／normalization 與 operational
   record 的對應；本契約不選這些形式。只畫幾個因果箭頭不足以證裝置存在。
2. **非平凡 response：兩段都必須成立。** 未來論證須先宣告合法操作、共同初態／
   非控制輸入的條件或分布、完整觀測量與同一讀出規則；以下是待證條件，沒有
   在本契約選擇任何 law、干預機制或數值門檻。
   - **A→B：** 至少兩個事前具名、可比較的 A 準備設定下，**B 自己的完整接收
     紀錄分布**不同；包括未接收、窗口外與歧義紀錄。比較的是合法準備干預下的
     law，不是只按 A 設定分組的相關。共同初態／背景須保持同一申報條件或 law，
     排除未控制的共同原因；不依成功接收／回訊、事後配對或其他 outcome 做挑選。
     不得從 A 設定外部重標記 B 的欄位來製造差異。deterministic law 可視為點質量
     分布，但仍須相同的操作與來源義務。
   - **B→A：** 固定 A 的準備設定、本地記憶、讀出規則與其他非回訊輸入，A 的
     最終回讀分布須依賴 B 端的實際回應。可選設定模式比較 B 的合法回應設定；
     固定自動模式須申報可合法改變 B 接收內容或回應操作的比較，不只對觀察到的
     B 內容條件化。A 不直接取得 B 設定、B 本地紀錄或對照分組標籤；其影響須經
     宣告的 B 回訊路徑，不能藉 pre-shared lookup 或 A 的準備記憶預寫答案。
   - **必備無回應對照：** 事前具名移除 B、阻斷其回訊或替換成不回應裝置中的
     一個合法對照；保留相同 A 準備／記憶／讀出規則，事前申報各 B 回應操作的
     對照對應，對應的無回應對照中 A 回讀分布相同（不對已移除的 B 虛構操作）。
     若移除 B 改變了其他環境條件，須給可比較性證據或改用
     有證據的阻斷／替換對照，不能默認只改了回應。無合法對照或無法隔離其他路徑
     時維持未決。**要消失的是 B 回應造成的依賴**；A 跨不同準備仍可保有本地記憶，
     那部分依賴不算訊號，也不能用來證成第二段。
   兩段與對照共同只是本回訊目標的必要條件，不單獨證明完整物理實現。依賴只能
   由 A 本地記憶解釋時記「非訊號」；若尚缺上述證明則未決。此標記不是正式 gate
   verdict。不能以 tag 一致、相關係數或畫出的箭頭代替任一段。
3. **可識別性：** 對完整允許紀錄類說明配對何時單值，以及不知道／多值時如何保留。
   若主張只用 intrinsic input，須按 Q 查同一 forgetful fiber 的目標值是否一致。
4. **穩定性與 failure：** 指明所有稱為可用的適用域及 perturbation／誤差前提；先寫
   欲證界的對象與 quantifiers，再給證據，不憑未來觀測挑數值 cap。機率 tail 不是
   本契約已獲授權的量測；未有 law 或證明即維持 OPEN，不稱可靠訊號。
5. **若用幾何 benchmark：** R 的 ideal rest echo 是已給 metric、刻度、null legs、
   零延遲與唯一回波的條件式參照，不能承擔本次實現。L 已示未知 response latency
   與距離無法由總回返時間分離；不得直接把回返時間稱距離。本問題不做 rod comparison。
6. **離散與連續的分界：** Z 的 uniform sprinkling 幾乎必然無精確 null point pairs，
   不等於不存在有效 light propagation；也不能要求每個訊號 leg 必是 sampled exact
   null pair，再把由此失敗誤報所有 B6 no-go。若聲稱 continuum 對應，另列其極限義務。

這些是探索設計的證明義務，**不是新 acceptance gates、numeric thresholds 或 verdict
taxonomy**。沒有符合條件的完整 law 時只報缺口；有條件模型也不等於真物質或 intrinsic 湧現。
